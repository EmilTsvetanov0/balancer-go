# Балансировщик нагрузки

Распределяет входящие запросы между заданным списком серверов, используя различные стратегии балансировки

## Для запуска

Выполните `docker compose up --build` в корневой директории

## Для тестов

1. Запустите сервис
2. Выполните `go test -bench=. -race ./tests` в корневой директории

## Настройка сервиса

Для изменения списка серверов, алгоритма балансировки, дефолтных лимитов для незнакомых клиентв и других параметров можно изменить соответствующие поля в файле `config/config.yaml`
В конфиге уже находятся все поля, которые участвуют в работе

Сервис поддерживает 3 основных алгоритма балансировки:

- round-robin
- least-connections
- random

И дополнительно два способа обновления состояния доступных токенов для ограничения количества запросов от одного клиента:

- interval
- time-based

`interval` - базовый способ, каждую секунду увеличивает количество токенов в бакетах

`time-based` - альтернативный способ, обращающийся к состоянию бакетов только при необходимости, но на каждое обращение производящий доп. операции на обновление временной метки и вычисление накопленного числа токенов

Для удобства поместил дополнительные комментарии в `config.yaml`
