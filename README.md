# Балансировщик нагрузки

Распределяет входящие запросы между заданным списком серверов, используя различные стратегии балансировки.

## Запуск

В корневой директории выполните:

```bash
docker compose up --build
```

## Тестирование

1. Запустите сервис.
2. Выполните:

```bash
go test -bench=. -race ./tests
```

## Swagger

Swagger-документация доступна по адресу:

```text
http://localhost:8080/swagger/index.html
```

> **Примечание:**
> Вместо `8080` укажите порт, который задан в файле `.env`.

## Настройка

Для изменения списка серверов, алгоритма балансировки, лимитов по умолчанию для незарегистрированных клиентов и других параметров — отредактируйте файл:

```text
config/config.yaml
```

Все необходимые поля уже присутствуют в конфиге и снабжены комментариями.

## Поддерживаемые алгоритмы балансировки

- `round-robin`
- `least-connections`
- `random`

## Ограничение скорости (Rate limiting)

Поддерживаются два метода обновления состояния токенов:

- `interval` — базовый способ, увеличивает количество токенов в бакетах каждую секунду.
- `time-based` — обновляет состояние токенов при каждом обращении с учётом прошедшего времени. Работает точнее, чем `interval`, но может создавать лишние операции при высоких нагрузках.

## Изменение порта

Порт сервиса задаётся в файле `.env`. При изменении порта автоматически обновляется и адрес Swagger UI.
