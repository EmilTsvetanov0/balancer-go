# Балансировщик нагрузки

Распределяет входящие запросы между заданным списком серверов, используя различные стратегии балансировки

## Для запуска

Выполните `docker compose up --build` в корневой директории

## Для тестов

1. Запустите сервис
2. Выполните `go test -bench=. -race ./tests` в корневой директории
